# 上海立信招聘内容系统（第一期本地原型）

## 截图转内容（2026-10-17）

启动后进入“来源监控 → 截图转招聘内容”，或打开 `http://127.0.0.1:8000/imports/screenshots`。同一批只处理同一单位的一篇公告：上传截图、填写来源信息并补充正文，点击“上传并识别”。原图、各分片识别结果和人工修改版分别保留；识别失败可重试，修改不会被晚到结果覆盖。

识别后先查看关键摘要与微信群、公众号内部预览。完整字段、原图、原文默认收起，需要修改时展开；问题列表可直接定位缺失或冲突字段。混合实习岗和高级岗时，可选择学生岗位子集，公共条件仍会保留；条件冲突需补连续原文依据。单位或岗位边界不清时，按页面提示拆批或完成人工范围确认。内部预览不能代替审核。

新版截图流程不要求手填质量分或逐项勾选六项核验。补齐真实来源和官方投递依据、处理红色问题后，审核员点击“我已核对关键内容，确认生成”，一次确认本版原文、范围、受众、地点、投递与时效；普通成员只能提交审核。后台记录实际操作者、时间、材料与岗位版本，不提高原质量分。只有当前版本的截图终审证明可替代数值评分门槛，其他岗位和旧流程仍保留 70 分规则。正式复制前系统会重新检查权限、状态和版本。事实变更、截止或撤销后，旧稿不能继续复制。系统不自动发送微信群消息或发布公众号文章。

- 输入支持 PNG、JPEG、静态 WebP，每批 1–5 张，单张最多 10 MiB、总计最多 25 MiB；长图自动分片，每批最多 24 片，合并正文最多 24000 字符。超限需裁剪或拆批，不静默丢弃尾部。
- 在“AI 模型配置”中配置并启用百炼 `qwen-vl-ocr`；字段整理使用当前启用的文本提供方，切换文本模型不会把图片发给该文本接口。图片会发送到已配置的识别服务；未配置时材料可保留，配置后重试。
- 本地正常启动会自动运行截图专用执行器；云端需运行独立 worker，并让网页和 worker 共用上传卷。原图保存在私有的 `data/uploads/recruitment/`，不公开、不入 Git，首版不自动删除。
- 邮箱、日期、薪资与工作地点不能猜补；无年份日期需核实，只有二维码时需补官方入口。没有链接可以保存待核验线索，不能据此直接生成正式稿。真实 OCR 效果仍需逐份对照，公众号后台粘贴后应人工检查排版。

### AI 自动预填与重试

截图先由 `qwen-vl-ocr` 识别成文字，再由当前启用的文本模型自动整理单位、岗位、受众、日期和投递信息。无需先手工填完整张表。页面会显示识别模型、字段模型、已预填数量和待核对项；已有识别正文时可点击“AI补全与整理”，不必重新上传图片或重复识别。

字段提取使用截图任务专用的固定 JSON 结构，不改变其他 AI 功能的请求方式。单个文本片段首次输出不合格时最多自动修复一次；部分字段引用不合格，不应导致其他有依据的内容整批丢失。接口不支持某个可选参数时只作一次兼容重试，不反复请求。模型、提供方和 Key 沿用现有配置，不自动切换。

AI 只预填有连续原文依据的事实，不把单位所在地猜成工作地点，不把某一个岗位的要求套到其他岗位。同一原文的修复只补不合格项，诊断解释或标签格式变化不会制造新的事实冲突。原文没有写明的选填字段可以留空，不用逐项勾选“原文未提供”；非空真实冲突、公共条件或岗位边界不明仍需处理，不能靠修改无关字段消除。硕博限定不自动判为本科核心适配，普通“硕士优先”也不当成硬性限定。

### 必填、选填与失败反馈

- 正式稿必需：单位、具体岗位或所选岗位、实际地点、学生受众、来源和官方投递依据。日期可以是有依据的完整日期，或摘要明确显示“公告未明确统一截止时间”；缺年份、过期或日期冲突不能猜补。
- 选填：薪资、职责、专业标签、岗位方向、招聘类型和内部地点分类。空值不阻止成稿；有实际冲突的非空内容需核实。AI 的依据说明、置信度和不确定项仅供查看，不要求人工逐项填写。
- 条件必填：邮件投递邮箱、必要附件、岗位独立条件、公共限制以及真实的受众或归属疑点。识别失败的图片不能自动视为完整原文，需补齐或明确核对完整手工正文。
- 已知问题会一起显示红标、具体原因和定位入口。最终确认先安全保存草稿，之后审核或生成失败仍保留本次输入；正式审核和生成结果整体回滚。并发冲突不覆盖他人的新内容，也不会自动把旧表单当成最新版提交。

本轮实现与验证见 [截图简化审核验收](docs/reports/2026-10-18-screenshot-guided-review-acceptance.md)。

重新提取或修改事实后，旧的人工确认、审核结果和正式稿复制资格需要重新核验。预填成功不代表审核通过，系统仍不自动发微信群或发布公众号。

## 项目更新登记规范

本项目每完成一项影响用户页面、数据、采集规则、外部接口或运行安全的重要更新，并完成验证后，必须在 `项目管理/项目推进台账.xlsx` 的“更新台账”页追加一条记录。记录应写明：完成日期、更新主题、更新简述、影响模块、验证结果、状态、风险或注意事项以及下一步。历史记录只追加，不覆盖；未实际落地的讨论和草稿不登记。

## 80 家分层来源库与每日采集 v2.2

在“来源监控”页面可查看 80 家分层来源：A 类 6 家已验证自动抓取、B 类 33 家核心专用适配库、C 类 21 家重点监控库、D 类 20 家观察库。新增的 7 所上海高校就业网与上海公共就业服务平台均处于 B 类禁用状态，只有 A 类来源参与每日采集；B/C/D 类不会自动抓取，也不会自动生成对外内容。

来源是否值得优先接入由“学生价值分”决定，综合上海岗位、实习/校招频率、财经专业匹配、官方报名入口完整度和公开页面稳定性。B 类来源必须完成公开页面试跑、连续三次成功、正文清洗合格并经人工确认，才可升级为 A 类。

双击 `install_daily_schedule.ps1` 可创建 Windows 计划任务 `LixinRecruiting-DueCollection`，每4小时唤醒一次；采集器会依照当季策略决定是否实际访问来源。电脑关机期间不会采集，下次任务会补做已到期的来源。点击页面的“运行每日采集”会立即复查所有已启用来源。

同一公告原文不变时，系统只更新最近成功复查时间；原文变化时，线索标记为“有更新”、清空旧核验清单，并重新等待人工核验。来源连续 3 次全量失败会自动暂停，需在来源监控页点击“恢复来源”后再继续采集。所有公开线索都保持“待核验”，不会自动发布任何招聘信息；对外发布前必须经过人工审核。

“上海华智公考（公众号招聘线索）”属于 C 类。它不自动发现或扫描公众号文章列表；运营人员只能在来源监控页粘贴公开 `mp.weixin.qq.com` 文章链接。系统读取到的内容仅生成待核验线索，必须补充政府、单位或官方报名系统的原文和报名入口后，才能进入后续审核；课程、培训和推广内容不会入库。

这是一个运行在本机浏览器中的招聘内容运营后台。第一期用于验证“来源—证据—岗位—审核—分发队列”流程；已接入多来源真实公开招聘试点，并支持将审核通过的岗位生成公众号富文本复制稿。系统不会自动发送公众号或微信群消息；AI 仅可辅助预填公告字段，所有字段仍需人工核对后才能进入审核。

## 启动

双击或在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\run_local.ps1
```

首次启动会自动创建本项目的 `.venv` 虚拟环境并安装所需组件。脚本会检查 Python 版本、依赖安装结果和 8000 端口；若端口已被旧服务占用，会停止并给出提示。启动后，在浏览器打开：

```text
http://127.0.0.1:8000
```

该地址仅能从这台电脑访问，不会对局域网或互联网开放。按 `Ctrl+C` 可以停止服务。

## 第一次怎么操作

1. 打开“仪表盘”，可看到10条明确标为演示的招聘记录。
2. 点击“运行模拟采集”，验证重复运行不会产生重复岗位。
3. 打开“岗位库”，选择“真实线索 / 待核验”，进入公告详情后点击“开始公告结构化”。
4. 对照公开原文补齐公告标题、具体岗位、官方报名链接、适合人群和报名安排；六项人工核验清单均需勾选。提交后岗位进入“待审核”。原文未写统一截止日期时，截止日期可留空，系统会标记为“公告未明确统一截止时间”，并在发布稿中提示尽快查看原文。
5. 在待审核岗位详情点击“通过”，系统会再次检查事实版本、时效、附件、核验清单和风险；通过后岗位变成“可发布”，并留下审核日志。
6. 点击“生成公众号和群消息”，到“待发送队列”查看两类内容。
7. 在公众号队列点击“打开公众号复制稿”，分别复制标题、摘要、富文本正文和微信群消息；将正文粘贴到公众号编辑器后，再人工检查并发布。

## 数据位置

- 本地数据库：`data/recruiting_local.db`
- 系统源码：`app/`
- 自动化测试：`tests/`

删除数据库文件会清空本地演示记录；下次启动时系统会重新生成演示数据。

## 当前边界

- 演示岗位均标明“演示数据”；公开采集线索均标明“待人工核验”，不代表已确认可投。
- 项目身份为“面向上海立信会计金融学院学生的非官方就业信息服务”，不代表学校官方立场或授权。
- 本期不保存学生简历、手机号、身份证、账号密码或其他个人求职数据。
- AI 可辅助公告字段预填、建议分和公众号内容提炼，但不会自动通过审核、自动发布、自动发送公众号或个人微信群消息。
- 公众号稿只在岗位事实版本与人工核验版本一致时可打开；公告更新后必须重新审核并重新生成。

## 与协作者同步（GitHub 私有仓库）

仓库只同步源码、测试、说明文档和项目台账；每位使用者的本地数据库、API Key、虚拟环境和临时导出文件均不会上传。协作者完成仓库授权后，运行以下命令即可在自己的电脑初始化项目：

```powershell
git clone <私有仓库地址>
cd shanghai-job-hub
powershell -ExecutionPolicy Bypass -File .\run_local.ps1
```

首次运行请先安装 **Python 3.10 或更高版本**，并在安装时勾选 **Add Python to PATH**。启动脚本会自动找到当前电脑的 Python、创建 `.venv`、安装依赖；不依赖任何人的用户名或 Python 安装路径。

启动后，在“AI 模型配置”页填写自己的百炼 API Key。密钥通过 Windows 凭据管理器保存在各自电脑中，不进入代码仓库。

真实官方来源采集、字段预填、建议分和审核规则均在本地运行。附件解析当前以已核验的 `.xlsx` 岗位说明为主；图片、扫描 PDF 等类型若未能解析，会保留为待核验材料而不会伪造字段。
