## 1. 上海商学院就业信息服务网

- 首页：https://jiuye.sbs.edu.cn/
- 职位列表：https://jiuye.sbs.edu.cn/PositionList.aspx/
- 职位详情示例：https://jiuye.sbs.edu.cn/PositionDetail.aspx?zwid=34575
- 检测时间：2026-09-16（Asia/Shanghai）
- 访问方式：匿名 `GET` 返回 HTTP 200；详情页匿名 `GET` 返回 HTTP 200。

### 1.1 列表与翻页证据

首页发现28个去重后的职位详情链接，链接形态为 `/PositionDetail.aspx?zwid=<数字>`。职位列表页每页显示10条；翻页是标准 ASP.NET 表单回传，不是把页码附到 URL：

- 表单：`POST https://jiuye.sbs.edu.cn/PositionList.aspx/`
- 隐藏字段：保留页面返回的 ASP.NET 隐藏字段。
- 下一页事件目标：`ctl00$content$GvPositionList$ctl13$btnNext`
- 实测：携带页面隐藏字段并提交该事件目标后，首条职位从 `zwid=34575` 变为 `zwid=34564`，确认能取得下一页，非重复响应。

因此适配器需要维护单个会话并按网页自身表单机制翻页；不得假设 `?page=2` 或使用未验证的接口。

### 1.2 职位详情字段证据

详情页使用表格字段，已在 `zwid=34575` 验证下列字段可取得：

| 目标字段 | 网页标签/来源 | 例子 |
| --- | --- | --- |
| 雇主 | `公司名称` | 上海吉祥航空股份有限公司 |
| 职位标题 | `职位名称` | 行政专员 |
| 职位类别 | `职位类别` | 全职 |
| 专业要求 | `要求专业` | 原文保留，不作推断 |
| 学历要求 | `要求学历` | 本科 |
| 地点 | `工作地区` | 上海市 |
| 发布日期 | `发布日期` | 2026年09月15日 |
| 截止日期 | `截止日期` | 2027年06月30日 |
| 正文 | `职位描述` | 含职责、任职要求及可能的报名方式 |
| 站内邮箱字段 | `简历投递邮箱` | 需与正文投递方式分别保存和核验 |

当前页面至少存在两种投递情形：

1. 吉祥航空样本在正文中列出校园招聘官方网址，站内也列出邮箱；正式记录应优先抽取正文中明确标注的官方投递入口，并将邮箱作为原始证据保留。
2. 部分转发公告的站内雇主是招聘服务公司，例如职位 `zwid=34572` 的站内雇主为北京网聘信息技术有限公司上海分公司，但职位标题为邮储银行上海分行校招。适配器不能无条件把站内“公司名称”作为最终雇主，须进入人工核验或只在正文可确定实际用人单位时结构化替换。

### 1.3 样本结果

对首页最新的10个去重职位详情逐条执行匿名读取，**10/10 返回 HTTP 200**。样本中同时存在：上海职位、外地职位、校招、以及招聘服务机构转发的职位。

- `34575`、`34574`、`34573`：上海吉祥航空的行政、培训与学习发展、商务职位；上海、本科、正文中有校园招聘表述。
- `34572`：职位标题指向邮储银行上海分行校招，但站内主体为招聘服务机构；需要实际雇主判断。
- `34570`：物产中大校招，工作地区为浙江；应由现有上海规则排除，不因专业匹配而入库。
- `34568`、`34453`、`34268`：西南证券职位，工作地区为重庆；应排除。
- `34567`：标题为中信银行武汉分行校招，工作地区为湖北；应排除。
- `34566`：申万宏源分支机构校招，工作地区字段为上海，存在站内邮箱；仍需检查具体分支地点和正文投递依据。

这证明来源能提供职位级正文和投递线索，也证明不能只按公司注册地址或标题筛选。正式采集必须以职位的 `工作地区` 和正文证据为准。

### 1.4 风险与适配边界

- 没有证据表明该站岗位只限上海商学院学生，但也不能据此声称无任何学校限制；适配器应保存原文，不生成“立信可投”的断言。
- 详情正文可能同时含多个岗位或地点。第一版将公告作为一个候选条目并保留全文；多岗位拆分必须有可验证的职位级边界，另立任务处理。
- 站内邮箱不自动等于官方邮箱；候选规则需要正文证据或人工审核。
- 不引入浏览器自动化、登录、验证码规避或高频访问。试采与正式采集沿用既有请求预算和间隔。

### 1.5 开发判定

通过P0开发前验收：可追溯列表、详情、正文、日期、地点和投递线索均存在，且翻页方法已通过实际请求验证。

建议稳定来源键：`sbs-jobs`；建议新模块：`app/sources/sbs_jobs.py`；建议测试：`tests/test_sbs_source.py` 与 `tests/fixtures/sbs/`。这些仅是下一阶段的拟定文件名，尚未创建。

## 2. 上海市企业服务云

- 入口：https://www.ssme.sh.gov.cn/public/recruit!jobIndex.do
- 检测时间：2026-09-16（Asia/Shanghai）
- 浏览器/普通网页入口可见招聘页面，但项目 `.venv` 中的 `httpx` 直接访问返回 HTTP 403，正文为“当前访问疑似攻击行为，已被网站管理员设置为拦截”。

这不表示该平台没有职位，也不代表用户的正常浏览器无法使用；它只说明**现有后端采集方式不能稳定、合规地读取该站**。不得通过伪造客户端特征、登录、验证码规避或浏览器自动化去绕过该拦截。

### 开发判定

不进入自动适配器开发和试采。运营人员可将其作为人工发现入口；如需导入具体岗位，必须取得原始链接、职位级正文、真实主体及投递证据，随后走现有人工审核流程。
