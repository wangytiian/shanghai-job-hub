## 4. 实施内容与边界

1. 修复 NCSS 主卡抽取，排除导航、隐藏弹窗、脚本等旁路文本。平台原生投递例外绑定官方 HTTPS 域名、真实详情路径、控件结构和持久化原文证据，不能靠“投递简历”四个字直接放行。
2. 新增两校公开 JSONP 适配器：固定列表/详情端点、纯 JSON 解析、严格 `wid` 身份、分岗正文与共同学历分离。列表工资字段不误当学历，不根据含义未知的日期字段猜截止日期。
3. 新增注协 HTML 适配器：只访问列表公开给出的同域 `rid`，提取真实职位要求、招聘联系方式与有效日期，保留协会声明，不枚举 ID。
4. 将四源接入既有隔离试采、白名单选样导入、审计与待核验页面；官方来源目录由 82 增至 85，其他 A 来源启用状态不变。
5. 明确硬性排除：硕士起、必须多年经验、已过期、本校专属、异地、无实际岗位正文或投递证据。可接受学历枚举包含本科时不误判成“必须硕士”；学生关键词不能盖掉资深经验要求。
6. 空分岗正文即使有共同学历也仍为空，不能用追加学历凑出“完整正文”。英文职责和真实“职位详情”标题可以识别，但不伪造原文标签。

没有改变数据库架构，没有启用新的自动采集调度，没有登录、绕过验证码/权限、关闭 TLS 验证或放开跨域重定向。实习僧及其他商业招聘平台授权 API 未接入，不应冒称已获得开放岗位接口。
