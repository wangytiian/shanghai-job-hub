1. 保存只读基线；真实写入前使用 SQLite backup API 备份到被忽略的 `outputs/` 子目录，保留原库，不覆盖旧备份。

3. SBS 常规仍最多 3 页，每次请求至少间隔 1 秒、单请求最长 12 秒、总预算 180 秒；不会用反复全站抓取制造数量。过滤原因与网络错误分开计数，样本错误有限记录。
4. 先跑离线回归，再经现有采集入口执行一轮真实补采。不使用付费模型调用。对新增逐条核对来源、日期、上海地点、正文、投递证据和受众待确认说明。
5. 重复采集验证幂等；全量 `python -m pytest -q`；重启已存在本地服务并检查主页和来源页。定时任务继续用原入口，不重复创建定时服务。
6. 7 天验收规则：最近完整 7 天 ≥7 条有效待审新增为最低产量目标；≥14 条为争取值，同时逐条确认人工可发布数。若低于 7，先区分未运行/解析失败/重复/过滤/源无新增，再从批次 2—3 选一个已有适配优质源；仍不足则每周人工精选补足缺口，不批量晋升未验证 B 源。

#### 第二供给渠道的实测结论与后续门槛

当前优先顺序：**SBS自动恢复 → 图片公告人工辅助补给 → 经核验的第二高校源**。现有平台数量多不等于可用供给多，不能盲升A。

1. 国资委图片是当前最大缺口：每周优先人工提取2—4篇近期校园招聘海报，回查上海子岗位、本科条件、截止日期、投递链接后再录入；可帮助覆盖本周至少7条的缺口，但人工动作尚未实施，不能计为已自动达标。若要自动图像识别，先用3篇脱敏真实样本评估识别准确率和成本，再单独配置识别服务，保留人工核验；本轮没有购买或启用此服务。

3. NCSS：1页10详情，4条可解析、6条正文仅标题，严格合格0。咨询管理/AI产品培训生等存在投递证据缺失；可作为人工发现入口，但没有验证登录投递，不绕过登录，也不当成已接入自动供给。
4. 持续7天统计≥7条非过滤、值得审核的真实新增为最低目标，≥14条为争取值；分别报告A/B、C受众待确认以及实际人工可发布数量。不能把D记录、复采、更新、旧公告补采堆出的日均作为成功证明。若仍不足，依上方实测缺口逐项补齐，不批量开发低质量入口。

## 1. 范围与放宽边界

- 地点仍以明确上海岗位为主；不在本轮悄悄取消现有上海校验。全国招聘中只提取明确上海的子岗位。
- 不限制企业上市状态、规模、知名度、所有制；不因企业不知名直接排除。
- 除金融机构外，覆盖商贸、物流、制造、互联网、专业服务等行业的匹配岗位。
- 覆盖实习、校招、明确接受应届生的社会招聘；经验不限但受众不明确的岗位进入待补证据，不直接合格。
- 薪资未披露不直接淘汰，不生成推测薪资；销售、派遣、外包、实习均明确标注。
- 不放宽真实雇主、岗位正文、投递证据、过期排除及人工审核；收费培训转就业、押金、明显虚假招聘不得发布。
- 招聘会邀请函不是岗位。可人工从参会企业清单发现雇主，只有取得具体职位正文和投递证据后才进入岗位审核。
- 学校转发不等于校方担保；平台发布者也不一定是实际雇主。不使用“二本友好”“保证录取”推断标签。
- 校内登录或仅限本校申请的来源不得绕过；不能把其他高校校内专属岗位推荐给立信学生。

## 5. 分阶段执行任务

### P0：基线与批次1入口勘查（约1—2个工作日）

产物：新建 `docs/sources/LIXIN_SOURCE_PROBE_REPORT.md`，每个入口一条记录；此阶段不写入正式岗位库。

- [ ] 从官方导航确认来源归属、列表地址、详情地址，记录检测时间与访问限制。
- [ ] 每站检查最近30天最多10条公告详情；不足时扩大至90天并标记老样本，不能计入近期新增。
- [ ] 记录：真实雇主、职位、上海地点、日期、专业/经验/届别、正文、投递证据、是否本校专属。
- [ ] 记录公开 HTML 或匿名接口的实际请求方式、分页参数和响应字段；不猜测 API 地址。

### P1：逐源完成解析与双通路接入（每种页面结构约1—2个工作日）

- [ ] 先保存经脱敏的真实 HTML/JSON fixture，编写失败测试：正确解析、正文为空、相对链接、分页、缺失日期、附件依赖。

### P2：受众规则复核（不与首个适配器同时扩大行为）

注意：默认每轮只读3条详情，3轮最多9个公告，无法满足累计10个公告。正式准入试验应使用每轮最多10条详情，并确保分页/样本选择能覆盖不同公告；不能通过反复抓同样几条凑数。

## 7. 工作量与停止条件

粗估：批次1的首个2源闭环约4—7个工作日，真实准入至少跨2天；每个后续批次至少留出7天观察窗口。估算以公开页面可读取为前提，不是交付时限承诺。

批次1成功定义：两个来源完成解析—试采—准入—正式采集闭环，或一个来源完成闭环且另一个有经证据确认的停止结论。后续批次沿用同一标准；质量条件不达标则交付明确阻塞及替补结果，而非把新增目录项当成采集扩充完成。
