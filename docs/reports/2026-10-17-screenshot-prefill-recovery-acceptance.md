## 改动

- 对截图字段请求附加封闭 JSON Schema；已知不支持可选参数的接口最多做一次兼容重试，其他 HTTP 错误不盲目重试。
- 第一次结构或证据不合格时，最多调用一次修复。仍有问题时逐字段保留通过原文校验的内容，标出待核对项，不再整表丢失。
- 每次恢复和最终分段合并均检查公共条件、岗位证据范围、冲突与待核对状态，保留原始 OCR 和识别来源。

- 重新提取会立即使关联岗位的旧审核和复制稿失效。即使队列已满，也不会留下仍可复制的旧稿。原有人审、发布与权限检查不撤销。

## 保留边界

AI 只能预填原文支持的事实。原文缺少的具体岗位、统一截止日期或官方报名链接仍须留空，不自动猜补。修复成功不等于公告已人工核验，也不自动发送微信群或公众号。

本次实际材料面向硕博，不能因模型给出“核心适配”等分类就当作本科适配岗位发布。学生适配、分发建议与归纳性表述仍须人工判断。重提取和保留有效字段已经验证，但没有声称本张材料已达到正式成稿条件。

本轮不验证真实微信后台粘贴、PostgreSQL 或云部署，不进行 GitHub 提交或推送。历史截图任务不会自动全量重跑，以免重复计费或覆盖人工工作。
