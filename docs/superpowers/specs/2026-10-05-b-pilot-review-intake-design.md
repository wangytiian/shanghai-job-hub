# B 类试采样本入库与人工升档设计

日期：2026-10-05。用户已确认：让选定 B 类来源的试点内容进入待核验岗位库，以提高可处理线索，但不得自动发布。

## 范围与边界

- 首批仅允许 `sufe-jobs`（上海财经大学就业网招聘）和 `sjtu-internships`（上海交通大学就业网实习）。来源保持 B 类、禁用日常采集；其他 B 类及 NCSS 不开放。
- 沿用现有有界 `source-trial`，试采本身仍只写 `SourceTrialRun`、`SourceTrialSample`；新增**逐条显式导入**动作，针对指定轮次中人工选中的样本导入 `Job` 待核验池。导入不等于来源晋升 A，也不等于发布。真实交大试采一轮同时出现适配线索和明确 `Top院校` 硬门槛，故不采用整轮无差别导入。
- 只有完成或部分完成的轮次可导入；来源未暂停、轮次归属及适配器／规则版本一致，样本身份与正文哈希仍有效。导入时重新按当前日期判断，已过期、非上海、资深、非岗位、正文／投递证据缺失的样本不得写入。
- `qualified` 样本可导入普通待核验；仅缺 `TARGET_AUDIENCE_UNCLEAR`、且无本校专属或经验硬限制的样本可作为 C 级人工复核线索导入。其他 `needs_evidence` 不导入。不得修改共享的 A 类来源准入规则来增加数量。
- 真实交大试采发现：有些岗位字段只写街道，正文却明确“工作地点：上海”，或单位地址明确上海且与岗位街道门牌相同。校园适配器可在**同一岗位的直接工作地点证据**或**同址证据**成立时补足城市；不得仅凭企业名称、学校所在地、任意上海字样或不相同的公司注册地址判定上海。显式外地岗位优先排除。共享候选规则仍不放宽。
- 同一来源、同一岗位身份重复导入不得重复建岗；正文发生事实变化时，旧核验和旧人工升档失效。导入记录保留来源键、run ID、sample ID，且新岗位始终标注尚未人工核验、不得对外发布。
- 服务调用也必须显式传入 1–10 个样本 ID，不允许遗漏参数时批量扫描整轮。较新试采如果明确证实同指纹旧岗位过期、外地、校内专属或缺核心证据，只能撤销旧核验并留档，不得新建可用岗位；较旧轮次不能再覆盖较新轮次，来源轮次高水位依据审计记录，不依赖人工核验时间。
- 来源原文或关键事实发生变化时，同时递增岗位事实版本与表单行版本；A 类商学院来源的复采亦遵循旧审核失效规则。C/D 级在发布前校验与最终审核两层均不可放行。
- 网页每次导入一个明确的 `sample_id`，服务端验证该样本属于指定轮次；没有选择不能导入，伪造的样本 ID 被拒绝。服务级批处理仍最多 10 个新岗位；未选择的样本原样留在报告中。带有明确 `Top院校` 等硬性学校门槛的样本不得导入；“知名高校”等模糊措辞需在后续人工审核时核对。云端只允许管理员执行导入，沿用登录和 CSRF 防护。

## 人工 C→B 复核

- 只处理真实、待核验、确认为新招聘、因**受众暂不明确**而落 C 的线索（包括本试点以及既有获准来源的同类线索）；不对 D 级或其他缺证原因开放。
- 审核员或管理员提交官方证据链接、连续原文摘录和判断说明。服务端验证字段、岗位当前版本及原文指纹；将等级改为 B，但状态仍为待核验，不直接给质量分、不自动进入内容队列。
- 同一事务记录 `ReviewLog` 与 `AuditEvent`，保留旧等级、新等级、证据和操作者；递增版本、清除旧核验及旧 AI 建议分。原文后续变化时重新落 C，并撤销这次人工判断的效力。
- 结构化、最终审核、`validate_publishable` 和分发 A/B 门槛保持独立。C 级不能仅因完成结构化而被当作可分发岗位。

## 用户可见流程

1. 从来源页对首批 B 来源发起试采，查看每轮样本与排除原因。
2. 管理员在试采报告上选择指定轮次执行“合格线索导入待核验”，获得新增、重复、跳过及原因汇总。
3. 岗位中心显示新线索；C 级可由审核员补证据升 B。所有线索仍需确认招聘类型、结构化、人工核验、最终审核，才能生成公众号／群内容。
4. 记录从试采列表到实际可发布内容的漏斗，不以原始采集量冒充日均产出。14 天观察窗口内报告去重后新增、人工通过、最终可发三个数；平均 1–2 条／日是试点目标，不保证外部网站一定提供足量合格岗位。

## 验收

- 离线固定样本测试证明白名单、来源归属、轮次状态、版本、过期、正文、投递、上海地点、校内限制、限量、去重、原文更新失效及权限均生效。
- 试采不会直接创建岗位；显式导入只创建待核验真实岗位；B 来源仍不进入每日 A 类调度；未完成人工核验的岗位无法生成发布内容。
- 在备份现有 SQLite 后，对两站分别进行一次真实、有界试采。只导入真实合格样本；若结果为零，则如实报告而不降低正文、时效或投递门槛。
