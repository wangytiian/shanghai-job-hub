# 上海华智公考公众号线索源接入设计

## 目标

把截图中确认的“上海华智公考”作为一个内部招聘线索来源接入系统，用于更早发现上海公务员、事业单位、国企、社工、辅警及编制外岗位公告。

## 来源定位与边界

- 来源名称：上海华智公考（公众号招聘线索）。
- 来源层级：C 类重点监控；70 家来源库扩展为 71 家，C 类由 20 家变为 21 家。
- 来源类型：公众号线索源；不等同于政府或单位官方招聘来源。
- 不登录公众号后台、不绕过验证码或反爬、不读取个人数据、不采集课程、报班、促销或社群信息。
- 只处理运营人员提供的公开文章链接，或可公开访问、无需登录的文章内容。
- 公众号文章永远不能直接生成对外发布内容。只有找到招聘单位、政府或官方报名系统的原文和报名入口后，才可提交人工审核。

## 使用流程

`运营人员粘贴公开文章链接 -> 系统读取公开标题与正文 -> 去除课程推广与无关内容 -> 生成内部待核验线索 -> 人工补充官方原文 -> 现有结构化、审核与分发流程`

当公开文章无法读取时，系统显示失败原因，不创建岗位；运营人员可在后续版本手工粘贴正文，但本期不把空内容当作招聘线索。

## 数据与状态

1. 来源目录新增上海华智公考记录，`adapter_key=wechat_article_lead`、`is_enabled=False`、`adaptation_status=重点监控`。
2. 新增“公众号线索导入”页面，只对该适配器的来源开放。
3. 导入成功创建真实 `Job`：`status=待核验`、`is_demo=False`、`official_url` 为空、`source_url` 为公众号文章链接、`evidence_text` 为提取后的公开正文。
4. 岗位标题使用文章标题；招聘单位初始为“待官方核验”；风险项明确写入“公众号线索，须补充官方原文和报名入口”。
5. 使用现有公告分类规则给出 `notice_type_suggestion`，但不能替代人工确认。

## 过滤与安全规则

- 链接必须是 `https://mp.weixin.qq.com/` 的公开文章链接。
- 正文为空、提取内容只有导航或少于最低文本长度时失败，不创建记录。
- 出现“课程、培训、报班、优惠、试听、开课”等推广信号且没有招聘/招录/报名等信号时，标记为非招聘，不创建岗位。
- 即使文章含招聘信息，也只保存必要事实摘要和原文证据，不复制图片、二维码、课程宣传和整篇排版。
- 相同文章链接重复导入时不创建第二条记录。

## 验收标准

1. 来源管理页显示 71 家来源，其中“上海华智公考”属于 C 类且不参与每日自动采集。
2. 公共文章链接可导入为待核验线索；无效链接、无法读取页面和纯培训推广内容不会生成岗位。
3. 导入线索必须保留公众号原始链接、提取证据、风险提醒和去重指纹。
4. 线索没有官方原文与报名入口时不能通过现有结构化校验进入可发布状态。
5. 现有 71 项自动化测试继续通过，并新增本功能的测试。
