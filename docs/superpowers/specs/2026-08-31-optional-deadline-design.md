# 招聘截止时间可选化设计

## 目标

让真实、可追溯但未写统一截止日期的招聘公告可以进入人工审核与发布，同时不把未知信息伪装成确定事实。

## 规则

截止时间只允许以下三种表达：

1. 公开原文明确的具体日期或时间；
2. 公开原文明确写明的“招满即止”；
3. “公告未明确统一截止时间”。

第三种不是缺失错误。它表示运营人员已查看原文，确认公告没有统一截止日期；仍须有官方链接、原文证据、明确的招聘事项、质量分和最终人工审核。空白截止时间在提交结构化表单时会被规范化为第三种表达，避免出现未说明的空字段。

## 渠道文案

当截止时间为“公告未明确统一截止时间”时，公众号和群消息不写“请在截止日期前”，而写“公告未明确统一截止时间，建议尽快查看官方原文或附件确认报名安排”。具体日期和“招满即止”保留原来的正常投递提示。

## 页面交互

公告结构化页将截止日期显示为“可选但必须如实标注”，并提示可留空（系统保存为公告未明确统一截止时间）。审核页不再把该状态显示为“占位字段”或退回理由；通过原因文案改为“已核对公开原文、官方入口、适合人群及报名安排”。

## 边界

这项变更不放宽来源真实性、官方入口、原文证据、附件核验、招聘事项或质量分要求；也不会自动发布任何内容。它只解决真实公告没有统一截止日期时被错误拦截的问题。
