# AI 公告预分类与结构化预填设计

## 目标

使用已配置的阿里云百炼 Qwen API，将公开招聘公告原文转换为可审核的结构化表单草稿，减少人工填写时间，同时保留人工对分类、归档、审核和发布的最终控制。

## AI 输入与输出

输入仅包括岗位标题、来源链接和采集原文证据，不包含学生个人信息或 API 密钥。

AI 返回固定 JSON：

- 公告类型建议：新招聘 / 招聘进度通知 / 非招聘信息；
- 招聘单位、岗位名称、岗位族、招聘类型；
- 地点、适合人群、专业方向、截止日期、官方报名链接；
- 每个关键字段的原文证据片段；
- 不确定项和风险提示。

缺失或无法从原文确认的字段必须返回空值，不得猜测薪资、编制、转正、专业不限、投递链接或截止日期。

## 操作流程

`待核验公告 → 点击 AI 预填 → AI 草稿 → 运营人员修改或确认 → 人工选择公告类型 → 提交待审核`

AI 预填不会改变岗位状态、公告类型或发布队列。只有运营人员点击分类和结构化提交，才会写入数据库。

## 接口与降级

复用现有“AI 模型配置”中的百炼 API Key 和文本模型。后端调用 API，浏览器不直接接触 Key。

模型不可用、响应不符合 JSON 或请求超时时，页面保留原手工表单和原文证据，并显示“AI 预填失败，可手工填写”。系统不得重试造成重复写入。

## 审核界面

结构化页新增“AI 预填”按钮。返回后：

- 表单填入 AI 建议；
- 显示公告类型建议与关键字段对应的证据；
- 空字段以醒目提示等待人工补齐；
- 提交前仍执行官方链接、适合人群、截止日期等确定性校验。

## 验收

1. 未配置 Key 时提示前往 AI 设置，不产生写入；
2. 合法 AI JSON 能预填表单但不改变岗位状态；
3. 缺失字段保持为空；
4. 非法 JSON 或模型失败降级为手工填写；
5. API Key 不进入浏览器、日志或 SQLite；
6. 全量测试通过。
