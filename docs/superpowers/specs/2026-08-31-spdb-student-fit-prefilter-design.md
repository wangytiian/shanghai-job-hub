# 浦发上海岗位学生适配预筛设计

## 目标

在上海浦东发展银行官方社会招聘来源进入人工待核验队列前，剔除有明确原文证据表明只面向成熟社招人员的岗位，减少运营人员无效审核量。

## 范围与边界

本规则仅作用于浦发上海官方详情页的候选记录，不改变公告原文、不自动发布、不替代人工审核，也不删除既有记录。

保留原则优先于过滤原则：只有招聘要求同时满足“明确多年经验”与“不含应届生开放信号”时才过滤。未写经验、经验表述模糊、或虽写一至三年经验但明确允许应届生/毕业生投递的岗位，均保留到人工待核验。

## 规则

1. 先执行现有硬过滤：仅上海、截止日未过、职位名不属于明确高管或团队管理岗。
2. 获取官网详情页的`hrsJobRequire`字段后，判定是否存在经验门槛。
3. 下列文字视为应届生开放信号：`应届`、`毕业生`、`校招`、`校园招聘`、`2026届`、`2025届`、`2024届`。
4. 下列文字视为成熟经验门槛：`3年以上`、`三年以上`、`5年以上`、`五年以上`、`三年及以上`、`五年及以上`，以及“工作经验/从业经验 + 3/5 年以上”的同义写法。
5. 存在成熟经验门槛且没有应届生开放信号时，不创建岗位记录；采集结果记录为“学生适配预筛过滤”的可解释原因。
6. `1-3年`、`1至3年`或`一至三年`本身不自动过滤：是否允许应届生需由人工在原文中判断。

## 可观察性

采集运行结果新增`filtered_jobs`与`filter_reasons`字段，来源监控摘要显示“创建、更新、预筛过滤”数量。这样运营人员能看见被排除的原因，而不是误认为来源没有更新。

## 测试与验收

- 要求“三年以上经验”且未提应届生的岗位不进入结果。
- 同样要求但明确“优秀应届生可投”的岗位保留。
- “1-3年经验”岗位保留。
- 既有地点、截止日期和高管岗位过滤继续有效。
- 运行全部测试，且本地来源页可显示本次运行结果。
