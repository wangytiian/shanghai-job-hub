# AI 学生适配判断与分层分发设计

## 目标

在现有“AI 公告结构化”之后，增加一层可追溯的运营判断。系统不仅提取公告事实，也根据公告全文和项目目标用户（大三、大四、应届生、毕业两年内）给出岗位族、地域、学生适配度与分发建议。

该层的目的不是让 AI 自动发布，而是减少运营人员重复判断，让不适合核心学生用户的真实招聘自动退出公众号与学生群待发布队列。

## 两层信息边界

### 原文事实层

只能填写公告中有直接依据的内容：招聘单位、岗位名称、资格要求、学历、经验、地点、报名时间、投递方式、邮箱或官方链接。每一项必须保留原文证据片段。原文未写时保持空值或明确标注“原文未明确”。

### AI 运营判断层

允许依据全文和固定词典生成建议，但必须显示为系统建议，不得冒充企业要求。包括：

- 岗位族（最多两个）；
- 地点分类与上海价值；
- 适合人群；
- 学生适配层级；
- 分发建议；
- 判断依据和置信度。

## 结构化输出规则

AI 返回原有事实字段，同时增加以下字段：

| 字段 | 可选值 / 格式 | 规则 |
| --- | --- | --- |
| `job_family` | 财会审计、金融银行、证券保险、税务评估、工商运营、数据技术、法律合规、公共管理、教育科研、综合职能等，最多两项 | 由岗位职责、岗位名称和专业要求映射；没有明确语义时填“综合职能”或留空。 |
| `location_category` | 明确上海、可选上海、全国、其他地区、原文未明确 | 公告单位或工作地点直接出现上海时为“明确上海”；全国岗位只有明确列出上海时为“可选上海”；不得从网址域名单独推断。 |
| `location_detail` | 事实地点说明 | 原文只确认上海但未给出校区/城市地址时填“上海（具体地点以原文为准）”。 |
| `target_audience` | 多标签 | 包含大三实习、大四/应届生、毕业两年内、社会人员、博士毕业生/博士后、高级专业技术人员、需按具体岗位判断。 |
| `student_fit_level` | 核心适配、补充适配、不适合核心学生用户、待人工判断 | 仅服务于内部运营和路由。 |
| `distribution_recommendation` | 进入学生分发审核、仅保留资料库、不进入学生分发 | 不等于发布决定。 |
| `rationale` | 不超过 160 字 | 说明判断原因，并引用关键要求。 |
| `confidence` | 高、中、低 | 依据完整度和冲突情况给出。 |

## 学生适配与路由规则

### 核心适配

满足以下任一条件：明确实习、校招、应届生、毕业两年内可投、管培生、初级岗位，且没有与学生群体冲突的硬性门槛。

系统建议：`进入学生分发审核`。仍须通过事实校验、质量评分与人工终审。

### 补充适配

真实招聘但主要面向研究生、博士、有限经验社招或特定技能人群；与核心学生的匹配度较低但可能存在少量适配情形。

系统建议：`仅保留资料库`。默认不生成公众号草稿和学生群消息；运营人员可手动改为审核发布。

### 不适合核心学生用户

出现以下任一明确条件：副教授及以上、高级职称、博士后/博士且未写应届本科可投、管理层/负责人、明确要求三年以上经验，或岗位受众与核心学生群体明显冲突。

系统建议：`不进入学生分发`。保留原始记录、结构化结果和判断依据，不删除、不自动对外发布。

### 待人工判断

附件缺失、岗位要求相互冲突、公告为多岗位但未拆分，或证据无法支持明确归类。

系统建议：`仅保留资料库`，并提示人工核验。

## 安全优先级

1. 来源真实性、岗位真实性、官方投递入口和有效性优先于 AI 判断。
2. 出现“博士”“高级职称”等限制时，限制条件优先于“面向社会公开招聘”等宽泛描述。
3. AI 不得推断薪资、编制、转正、户口、专业不限、具体校区地址或截止日期。
4. AI 判断与原文事实冲突时，保留原文事实并标记“待人工判断”。
5. 所有分发动作仍以人工终审为前提。

## 页面与交互

AI 预填成功后，表单分为“原文事实”和“运营判断”两个区域。

- 事实字段展示证据片段；
- 运营判断字段显示“AI 建议”标签、置信度和依据；
- 地点字段必须使用 AI 草稿值，而不是继续显示采集阶段占位值；
- 适合人群改为多选标签，新增“博士毕业生/博士后”“不适合学生主分发”等结果；
- 运营人员可一键接受建议，也可手动覆盖；覆盖操作写入审核记录；
- 当分发建议为“仅保留资料库”或“不进入学生分发”时，不创建公众号和微信群待发送队列。

## 示例：上海市团校公告

| 项目 | 结果 |
| --- | --- |
| 岗位族 | 教育科研、公共管理 |
| 地点分类 | 明确上海 |
| 工作地点 | 上海（具体地点以原文为准） |
| 适合人群 | 博士毕业生/博士后、高级专业技术人员 |
| 学生适配 | 不适合核心学生用户 |
| 分发建议 | 不进入学生分发 |
| 依据 | 原文明确要求副教授及以上，或博士毕业生/出站博士后。 |
| 置信度 | 高 |

## 验收标准

- AI 预填后，地点字段能显示 AI 返回的真实结果，采集占位值不得覆盖它。
- “学生适配”和“分发建议”均有依据与置信度。
- 不适合核心学生用户的公告不能自动生成学生渠道内容。
- 运营人员可覆盖 AI 建议，且覆盖记录可追溯。
- 事实字段与运营判断在页面上清晰区分。
- 现有人工终审和发布安全门槛不被绕过。
