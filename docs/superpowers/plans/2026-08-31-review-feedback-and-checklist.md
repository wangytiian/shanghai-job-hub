# 审核反馈与发布检查清单 Implementation Plan

**Goal:** 审核操作停留在当前岗位页，并展示成功/失败反馈与可读的发布条件清单。

**Architecture:** 详情页将发布校验结果作为页面数据渲染；审核 POST 在当前页面返回结果卡，而不是只做重定向或技术错误。审核备注使用预设选项，并允许补充说明。

### Task 1: 审核反馈

- [ ] 为通过、退回和淘汰操作写网页失败测试。
- [ ] 审核接口在成功/失败后返回同一岗位详情页，展示反馈文本。
- [ ] 运行测试确认操作结果可见。

### Task 2: 发布检查清单与说明选项

- [ ] 为缺失字段的发布检查清单写失败测试。
- [ ] 展示可发布/不可发布及具体原因；用下拉选项承载常见审核结论。
- [ ] 运行全量回归测试和本地页面检查。
